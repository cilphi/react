# Títulos del Proyecto

Descripciones del proyecto

## Instalación 

Las instrucciones para descargar y configurar el proyecto:

```bash
    git clone https://github.com/tu-user/tu-repo
    cd tu-repo
    npm install
```
## Contribución

Instrucciones para contribuir:

1. Haz el **fork** del proyecto
2. Crea una **branch**
3. Realiza tus cambios y has un **commit**
4. **Sube** tu rama
5. Abre un **pull request**

### Comandos usados:

Para más información [Revisa esta guía](https://docs.github.com/es/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax)

- Visualizar en VS Code: Ctrl+Shift+V
- Un numeral para iniciar el Título principal
- Dos numerales para subtítulo
- Usar una caja para destacar texto: 
    - Se escribe triple backticks + bash
    - Se cierra  con triple backticks
- Lista ordenada:
    - Se anota el número + un punto y un espacio
- Doble asterisco para usar bold
- Tres numerales para el nivel 3 de título
- Hipervínculos:
    - Se abren corchetes para el texto a clickear
    - Sin espacear se pega entre paréntesis el vínculo
- [x] Tarea completada
- [ ] Tarea pendiente
